# Paper-Collage Visual System Skill — Growing Worlds

## 1. Aesthetic Vision
- Tactile papercraft diorama aesthetic: layered construction paper, torn deckled edges, gentle angle skews (-2° to +2°), and physical drop shadows.
- No photorealistic 3D gloss; use flat/layered vector styling with clean silhouettes.

## 2. Shadow & Filter Tokens
- Paper cutout shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.12), 0 2px 4px -2px rgba(15, 23, 42, 0.08)`
- Elevated paper shadow: `0 10px 15px -3px rgba(15, 23, 42, 0.16)`
- Paper grain SVG filter overlay with subtle feTurbulence.

## 3. Contributor Name Tag Design
- Mini luggage tag / paper pin label attached underneath or adjacent to the placed object.
- Features circular GitHub avatar, `@username`, and subtle paper cardstock background.
