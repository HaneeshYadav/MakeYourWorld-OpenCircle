# Security Policy

## Supported Versions

Growing Worlds is actively maintained on the latest versions:

| Version | Supported          |
| ------- | ------------------ |
| `main` / `dev` | :white_check_mark: |
| `< 1.0.0`     | :white_check_mark: |

---

## Reporting a Vulnerability

We take the security of **Growing Worlds** and our community very seriously.

If you discover a security vulnerability, please **do not open a public GitHub issue**. Instead, follow these responsible disclosure steps:

1. **GitHub Security Advisory**: Use GitHub's private vulnerability reporting feature by visiting the **Security** tab -> **Advisories** -> **Report a vulnerability**.
2. **Include Details**:
   - Clear description of the potential vulnerability.
   - Steps or proof-of-concept (PoC) to reproduce the issue.
   - Affected files, dependencies, or components.
   - Impact assessment on the web application or contributors.

### What to Expect:
- **Acknowledgement**: You will receive an acknowledgement from the maintainers within 48 hours.
- **Remediation**: We will review, patch, and release a fix in a timely manner before publicly disclosing the advisory.
- **Credit**: We are happy to credit security researchers who adhere to responsible disclosure guidelines.
